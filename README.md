# java-exercises

Questo repository contiene una varietà di esercizi pratici suddivisi per argomento e complessità, ideali per studenti, autodidatti e chiunque voglia migliorare la propria conoscenza del linguaggio Java. Sono gli esrcizi con cui ho imparato a programmare e spero possano tornare utili a qualcun'altro. :)

## Struttura del repository

Il contenuto è suddiviso in cartelle tematiche:

### `basic 1`
Contiene esercizi fondamentali su:
- Operazioni con stringhe (`Anagrammi`, `StringParser`, `PrimaRipetizione`)
- Strutture di controllo (`CiaoMondo`, `Fattoriale`, `Gradini`, `PotenzaDiDue`)
- Matematica e logica (`Tartaglia`, `Eratostene`, `Crivello`, `CalcoloPolacco`)
- Input/output e formattazione (`Cent`, `Verticale`, `OrdineAlfa`)
- Altri esercizi introduttivi (`AlfaFarfa`, `Mat`, `Ordine`, ecc.)

### `basic 2`
Esercizi leggermente più avanzati, tra cui:
- Gestione delle eccezioni (`Eccezioni_ContaNumeri`)
- Analisi e manipolazione di stringhe (`Parole`, `ParoleCrescenti`, `SommaParolePari`)
- Lavoro con metodi e classi (`DisegnaTriangoliRettangoli`, `StringParser`)

### `basic 3`
Contiene:
- Strutture dati personalizzate (`PoorMansHash`, `MyPoorHash`)
- Algoritmi testuali e di disegno (`Righello`, `TrieRettangoli`, `SommaParolePari`)

### `disegni iterati`
Esercizi grafici e algoritmi di stampa:
- Triangoli e figure (`TriangoloFede`, `Alfatri`, `ProvaTriangolo`)
- Animazioni di base o giochi (`Snake`)
- Disegni iterativi (`Disegno`, `Es3`, `Es4`)

### `ricorsione`
Esercizi focalizzati sulla programmazione ricorsiva:
- Algoritmi ricorsivi (`Ricorsione2.java`)
- Include anche la libreria `aplu5.jar` per grafica o logica avanzata

## Requisiti

- **Java JDK** (versione 8 o superiore)
- Un IDE Java (consigliato: IntelliJ IDEA, Eclipse, o VSCode con estensione Java)
- Per alcuni esercizi, potrebbe essere necessario configurare la classpath (es. `aplu5.jar`)
